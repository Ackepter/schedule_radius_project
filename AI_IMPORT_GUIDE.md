# Инструкция для ИИ: как составить JSON для загрузки в приложение

В этом документе описан формат файла `backup.json`, который можно загрузить через
раздел **«Для разработчика» → «Выбрать JSON-файл»**.

Задача ИИ — взять **рукописные записи** (списки учеников, педагогов, направлений,
кабинетов, расписания на неделю) и превратить их в такой JSON. Текст записи может
быть в свободной форме, с опечатками и сокращениями — нужно нормализовать данные
в строгий формат ниже.

> Экспорт из программы (кнопка «Выгрузить JSON») создаёт файл в **этом же формате**,
> поэтому его можно использовать как пример и как шаблон.

---

## Общие правила

1. Файл — один JSON-объект, корневой элемент **не массив**.
2. Поля, которые неизвестны или не указаны в записях, можно **пропускать** или
   ставить `null`. Обязательны только ключевые поля (имя, фамилия и т.п.).
3. **Все связи задаются по именам, а не по числовым id.** Имена должны точно
   совпадать с тем, что указано в разделах `subjects`, `teachers`, `students` и т.д.
4. Время — строка `"ЧЧ:ММ"` (24-часовой формат), например `"14:00"`, `"09:30"`.
5. Дата — строка `"ГГГГ-ММ-ДД"`, например `"2014-03-12"`.
6. Дни недели — числа: `0` = Понедельник, `1` = Вторник, `2` = Среда, `3` = Четверг,
   `4` = Пятница, `5` = Суббота, `6` = Воскресенье.
7. Тип занятия: `"individual"` (индивидуальное) или `"group"` (групповое).
8. Кодировка — UTF-8. Русские буквы обязательны (не транслит).
9. Статус расписания: `"draft"` (черновик) или `"active"` (активное).

## Описание полей и типов

### `subjects` — направления (список)
| Поле | Тип | Описание |
|---|---|---|
| `name` | строка | Название направления. **Обязательно.** Уникально. |
| `description` | строка | Описание. |
| `default_duration_minutes` | число | Длительность занятия по умолчанию (минуты). |
| `is_active` | boolean | Активно ли направление. |

### `teachers` — педагоги (список)
| Поле | Тип | Описание |
|---|---|---|
| `first_name`, `last_name` | строка | Имя и фамилия. **Обязательны.** |
| `comment` | строка | Комментарий. |
| `is_active` | boolean | Активен ли педагог. |
| `max_weekly_hours` | число | Максимум часов в неделю. |
| `subjects` | массив строк | Направления, которые ведёт (по именам из `subjects`). |
| `availability` | массив | Доступность (см. ниже). |

### `rooms` — кабинеты (список)
| Поле | Тип | Описание |
|---|---|---|
| `name` | строка | Название. **Обязательно.** Уникально. |
| `capacity` | число | Вместимость (мест). |
| `comment` | строка | Комментарий. |
| `allowed_subjects` | массив строк | Разрешённые направления. |
| `availability` | массив | Доступность. |

### `availability` — доступность (внутри педагога/кабинета/ученика)
Каждый элемент:
```json
{ "day_of_week": 0, "start_time": "14:00", "end_time": "19:00" }
```

### `parents` — родители (список)
`first_name`, `last_name` — **обязательны**. Остальное: `phone`, `email`, `comment`.

### `students` — ученики (список)
| Поле | Тип | Описание |
|---|---|---|
| `first_name`, `last_name` | строка | **Обязательны.** |
| `birth_date` | дата | `"ГГГГ-ММ-ДД"` |
| `parent` | строка | «Фамилия Имя» родителя из `parents`. |
| `is_active` | boolean | Активен ли. |
| `availability` | массив | Доступность. |
| `lesson_requests` | массив | Требования (см. ниже). |

### `lesson_requests` — требования ученика (внутри ученика)
| Поле | Тип | Описание |
|---|---|---|
| `subject` | строка | Направление по имени. **Обязательно.** |
| `lesson_type` | строка | `"individual"` или `"group"`. |
| `lessons_per_week` | число | Сколько занятий в неделю. |
| `duration_minutes` | число | Длительность (минуты). |
| `preferred_teacher` | строка | «Фамилия Имя» предпочтительного педагога. |
| `teacher_is_required` | boolean | Обязателен ли именно этот педагог. |
| `priority` | число | Приоритет: 1 — низкий, 2 — средний, 3 — высокий. |
| `notes` | строка | Примечания. |

### `group_lessons` — групповые занятия (список)
| Поле | Тип | Описание |
|---|---|---|
| `title` | строка | Название группы. **Обязательно.** |
| `subject` | строка | Направление по имени. **Обязательно.** |
| `teacher` | строка | «Фамилия Имя» педагога. |
| `teacher_is_required` | boolean | Обязателен ли педагог. |
| `duration_minutes` | число | Длительность. |
| `lessons_per_week` | число | Раз в неделю. |
| `max_size` | число | Максимум участников. |
| `comment` | строка | Комментарий. |
| `students` | массив строк | «Фамилия Имя» участников из `students`. |

### `prices` — цены (список)
| Поле | Тип | Описание |
|---|---|---|
| `subject` | строка | Направление по имени. |
| `lesson_type` | строка | `"individual"` или `"group"`. |
| `min_participants` | число | Мин. число участников для тарифа. |
| `max_participants` | число | Макс. число участников для тарифа. |
| `price_per_student` | число | Цена за занятие с одного ученика (руб.). |

### `optimizer_settings` — настройки оптимизатора (один объект)
`time_limit_seconds` (лимит расчёта), `early_hour`/`late_hour` (рабочий диапазон),
весовые коэффициенты (`weight_presence`, `reward_preferred_teacher`,
`penalty_student_same_day`, `penalty_early_late`, `weight_teacher_balance`,
`weight_room_balance`). Можно пропустить целиком — используются значения по умолчанию.

### `schedules` — расписания (список)
Каждое расписание: `name`, `week_start` (дата начала недели), `status`,
`unscheduled_report`, и `lessons` — список занятий:
```json
{
  "lesson_type": "individual",
  "student": "Иван Иванов",
  "subject": "Математика",
  "group": "Математика 5 класс",
  "day_of_week": 2,
  "start_time": "16:00",
  "end_time": "17:00",
  "teacher": "Анна Петрова",
  "room": "Кабинет №1"
}
```
- Для индивидуального занятия укажите `student` и `subject`; для группового — `group`
  (название группы). Остальные поля общие.

---

## Правила при переводе рукописных записей

- **Имена приводите к единому виду** «Фамилия Имя» во всех ссылках
  (в `parent`, `preferred_teacher`, `teacher`, `students`, полях занятий).
- Опечатки, сокращения ("матем.", "англ.", "программир.") разворачивайте в полные
  названия направлений — они должны совпадать со списком `subjects` ровно.
- Если имя ученика встречается в нескольких группах — используйте одинаковое
  написание во всех местах.
- Не добавляйте поля `id` — программа назначает их сама.
- Раздел `schedules` можно не указывать, если расписание ещё не составлено —
  программа построит его сама через оптимизатор.

---

## Как загрузить файл

1. Откройте раздел **«Для разработчика»** в левом меню.
2. Нажмите **«Выбрать JSON-файл»**.
3. Подтвердите замену данных.
4. После загрузки появится отчёт: сколько сущностей импортировано и список замечаний
   (например, если на ссылку по имени ничего не нашлось).
